# 🎂 Birthday Surprise Website

An interactive cinematic birthday surprise website built with HTML, CSS, JavaScript, GSAP, and Vite.

## ✨ Features

- 🎁 Animated gift box opening
- 🎵 Stage-based background music
- 🎂 Interactive birthday cake
- 📸 Cinematic memory gallery
- 💌 Animated letter with typewriter effect
- 🎆 Fireworks celebration
- ❤️ Hidden romantic message
- 📱 Fully responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES Modules)
- GSAP
- Canvas Confetti
- Vite

## 🚀 Run Locally

```bash
npm install
npm run dev
```
